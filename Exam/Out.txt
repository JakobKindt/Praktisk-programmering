Now I test the algorithm on a more complicated function which is the sum of 4 gaussian functions in 4D (where I have no analytical expression for the minima, but given the weights and standard deviations of the gaussian functions, see main directly, the minima should be close to the center of the third gaussian function by design). Here I use 5 particles. 

System has converged prematurely after 2258 steps.
Global optimal position = {-0.614568, 0.805686, 0.54686, -1.26137}
Global optimal value = -7.89512
The algorithm took 4 milliseconds. 

Now with rattle. 
System has converged prematurely after 6228 steps.
The system was rattled 384 times. 
Global optimal position = {0.114314, 1.18584, 0.366488, -0.391947}
Global optimal value = -15.2527
The algorithm took 14 milliseconds. 

In this case, rattle made it roughly 6 times slower and once again got sightly closer to the global minima which is a proof of concept for why rattle might be usefull. However, if we use PSO more like intended and have a decent amount of particles, i.e. 25 instead of 5, we also get closer to the global minima and it is faster than with rattle.

System has converged prematurely after 1949 steps.
Global optimal position = {0.155996, 1.17543, 0.418395, -0.341962}
Global optimal value = -15.4942
The algorithm took 20 milliseconds. 

This shows that if one needs to find the minima, it is more useful to simply increase the number of particles.
